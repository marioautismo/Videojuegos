# Videojuegos Singulares

Videojuegos de Singular Club.

- **Máscara** (`mascara/`): endless runner sobre el coste del masking. Saltas lo que hay en el suelo, eliges entre la máscara de fluidez y la de ocultación según quién tengas delante y recargas en las zonas seguras. Cada 1000 m hay una reflexión sobre los tres tipos de masking y un escenario nuevo.
